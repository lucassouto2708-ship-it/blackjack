# Blackjack

Jogo de Blackjack (21) para jogar no navegador, com fichas, aposta e as jogadas de sempre: pedir, parar, dobrar e dividir.

## Como jogar

1. Abra `index.html` no navegador (duplo clique).
2. Escolha as fichas para montar a aposta e clique em **Distribuir**.
3. Use **Pedir**, **Parar**, **Dobrar** ou **Dividir** conforme a mão.
4. Ao fim da rodada, clique em **Nova Rodada**.

## Requisitos

- Um navegador moderno.
- Conexão com a internet, porque as cartas vêm da API pública [Deck of Cards](https://deckofcardsapi.com).

## Arquivos

- `index.html`: o jogo inteiro (estilo, lógica e áudio em um único arquivo).
